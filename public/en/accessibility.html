Accessibility Statement

At Wish Tree, we are committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards across all platforms and devices.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. Wish Tree aims to conform with WCAG 2.1 Level AA guidelines.

Key Accessibility Features

Our website incorporates the following accessibility features:

  • Semantic HTML Structure: Clear landmark elements (<header>, <main>, <aside>) and hierarchical headings for straightforward screen reader navigation.
  • Keyboard Navigation: All interactive controls, dialogs, and wish submission forms are fully accessible via keyboard (Tab, Shift+Tab, Enter, Space, and Escape).
  • Screen Reader Support: Polite live regions (aria-live="polite") announce live wish counts, and modal dialogs use proper ARIA attributes.
  • Contrast & Typography: High color contrast between text and background surfaces, paired with readable fonts (Manrope and Fraunces).
  • Reduced Motion: Automatically honors user preferences for prefers-reduced-motion by subduing falling petals and background animation effects.
  • Mobile & Desktop Responsive: Fluid layouts that adapt gracefully to screens of all sizes, supporting up to 200% text zoom without loss of functionality.

Interactive Graphics & Fallbacks

While the tree visualization is rendered using SVG and HTML5 Canvas, critical functions such as viewing wish counts and making wishes are fully accessible via standard form controls and accessible dialogues.
